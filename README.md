# This mod is a port of [VoidMiners-Reforked](https://www.curseforge.com/minecraft/mc-mods/voidminer-forked) for 1.21.1 using the amazing work made by SrNadien in his own port to 1.21.1 [Void-Miners-Remastered](https://www.curseforge.com/minecraft/mc-mods/void-miners-remastered).

## This mod has [JEI](https://www.curseforge.com/minecraft/mc-mods/jei), [JADE](https://www.curseforge.com/minecraft/mc-mods/jade) and [KubeJS](https://www.curseforge.com/minecraft/mc-mods/kubejs) integrations.

## See the [wiki](https://github.com/Minimaxi28/VoidMiners-Remastered-Reforked/blob/Neo/1.21.1/wiki.md) for how to use the KubeJS integration.

## Please report any bug to the [GitHub issue tracker](https://github.com/Minimaxi28/VoidMiners-Remastered-Reforked/issues).

## There are 2 config files, `voidminers-miners.json5` and `voidminers-solars.json5` located in `minecraft\config\`. They will be generated at launch, and you can change them and reload the world to apply, no need to restart the game.
